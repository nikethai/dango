# Monkey test of the web build (2026-10-31)

Step 2 of the [desktop testing plan](../specs/2026-10-31-desktop-testing-after-codex-walk.md), run while Codex was out of quota. Target: `pnpm dev:web` on a local branch `qa/monkey-all-fixes` (main plus the nine fix branches from step 1, not pushed). Disposable browser profile, loopback fake provider only, no real accounts. Node 22.

## How it was run

- **Seeded monkey** (`monkey.js`, injected into the page): random clicks, typing (paths, Unicode, markdown, `<tool_call>`, long text, slash and @ tokens) and keys (Esc, Enter, Tab, arrows, ⌘K, ⌘Z, ⌘N, ⌘\). Every request to anything other than the app and the fake provider is blocked, and so are new windows. After each action it checks for uncaught errors and unhandled rejections, raw error codes or tool markup in answers, a crash screen, "Stopped before answering" while Stop is visible, an error notice while Stop is visible, Stop stuck over 45 s, a chat with no message rows after 6 s, horizontal page scroll, and controls with no accessible name.
- **Runs:** seed 1 (300 actions, 1024 px), seed 2 (400 actions, 1024 px), seed 3 (250 actions, 390 px). None raised a console error, an uncaught error or an unhandled rejection, and none tried to reach an outside host.
- **Targeted chat scenarios** with new fake-provider modes: `slow-4` (Stop before the first word), `empty`, `drop` (stream cut off), `401`.
